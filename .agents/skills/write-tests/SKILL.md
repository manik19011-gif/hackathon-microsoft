# Write Tests

## Steps

1. **Identify what to test** — Read the source code and understand the function/module's responsibility.
2. **Choose the test type** — Unit test for pure logic, integration test for API/DB, E2E test for user flows.
3. **Set up test infrastructure** — Ensure test runner, assertions, and mocks are available.
4. **Write happy path tests** — Test the expected, normal behavior first.
5. **Write edge case tests** — Empty inputs, nulls, boundary values, large inputs.
6. **Write error path tests** — Invalid inputs, network failures, missing data.
7. **Run the tests** — Execute and verify all tests pass.
8. **Check coverage** — Identify untested branches and add tests if needed.
