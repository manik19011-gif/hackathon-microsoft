# Implement a Feature

## Steps

1. **Review the plan** — If a plan exists, follow it. If not, create one first using the plan-feature skill.
2. **Set up the foundation** — Create necessary directories, install dependencies, set up configuration.
3. **Build data layer first** — Create models, schemas, database migrations, and data access functions.
4. **Implement business logic** — Write the core logic, services, and utilities.
5. **Build the API layer** — Create routes, controllers, middleware, and request validation.
6. **Build the UI** — Create components, pages, forms, and connect to the API.
7. **Write tests** — Add unit tests for business logic and integration tests for API endpoints.
8. **Run quality checks** — Execute linting, type checking, formatting, and all tests.
9. **Document** — Update README, add API docs, document environment variables.
10. **Self-review** — Re-read all changes for bugs, security issues, and missing edge cases.
