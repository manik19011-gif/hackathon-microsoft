# Plan a Feature

## Steps

1. **Clarify requirements** — Ask what the feature should do, who uses it, and what constraints exist.
2. **Identify affected files** — Search the codebase for related components, routes, models, and tests.
3. **Design the approach** — Outline the implementation plan:
   - New files to create
   - Existing files to modify
   - Database schema changes
   - API endpoints to add
   - UI components needed
4. **Identify risks** — Note potential breaking changes, performance concerns, or security implications.
5. **Define acceptance criteria** — List what "done" looks like, including tests.
6. **Present the plan** — Show the plan to the user for approval before any implementation.
